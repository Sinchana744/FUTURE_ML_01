# FUTURE_ML_01 – Student Performance Prediction

## 📌 Internship Project

This project is developed as part of the Future Interns Machine Learning Internship.

The objective of this project is to develop a Machine Learning model that predicts a student's final academic score based on study habits and academic performance factors.

---

## 🎯 Problem Statement

Student academic performance can be influenced by factors such as:

- Hours studied
- Attendance
- Previous academic score
- Assignment completion

This project uses these factors to predict the student's final score using Machine Learning.

---

## 🚀 Project Features

- Data loading using Pandas
- Data preprocessing
- Machine Learning model training
- Linear Regression model
- Model evaluation using MAE and R² Score
- Final score prediction
- Actual vs Predicted visualization
- Interactive Streamlit web application

---

## 🧠 Machine Learning Model

### Linear Regression

Linear Regression is used to establish the relationship between the input features and the final student score.

### Input Features

| Feature | Description |
|---|---|
| Hours_Studied | Number of hours studied |
| Attendance | Attendance percentage |
| Previous_Score | Previous academic score |
| Assignments | Number of completed assignments |

### Target Variable

`Final_Score`
