# FUTURE_ML_01 - Student Performance Prediction

## Project Overview

This project develops a Machine Learning model to predict a student's final academic score based on academic performance factors.

## Features

- Hours Studied
- Attendance Percentage
- Previous Score
- Assignments Completed

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Streamlit

## Machine Learning Model

Linear Regression is used to predict the final student score.

## Application

The trained model is deployed using a Streamlit web application that allows users to enter student details and receive a predicted final score.

## Model Evaluation

The model is evaluated using:

- Mean Absolute Error (MAE)
- R² Score
